Dự án Website Bán Hàng Nội Thất (WebsiteBanHangOnline)

Đây là một dự án website thương mại điện tử chuyên bán các sản phẩm nội thất. Dự án được xây dựng như một bài tập lớn cho môn học Lập trình Web Nâng cao, thể hiện kỹ năng xây dựng ứng dụng web hoàn chỉnh với ASP.NET MVC 5.

 🚀 Các chức năng chính

👨‍💻 Phía người dùng (Client)
- [x] Xem danh sách sản phẩm theo danh mục và theo xu hướng.
- [x] Tìm kiếm sản phẩm theo tên.
- [x] Xem thông tin chi tiết của sản phẩm.
- [x] Thêm sản phẩm vào giỏ hàng.
- [x] Quản lý giỏ hàng (Cập nhật số lượng, xóa sản phẩm).
- [x] Đăng ký, đăng nhập tài khoản người dùng.

 Phía quản trị viên (Admin)
- [x] Đăng nhập vào trang quản trị riêng.
- [x] Quản lý Sản phẩm (Thêm / Sửa / Xóa).
- [x] Quản lý Danh mục sản phẩm.
- [x] Quản lý Đơn hàng.
- [x] Quản lý Tài khoản khách hàng.

🛠️ Công nghệ sử dụng

*   Ngôn ngữ: C#
*   Backend: ASP.NET MVC 5, Entity Framework 6 (Code First)
*   Frontend: HTML5, CSS3, JavaScript, Bootstrap
*   Cơ sở dữ liệu:Microsoft SQL Server
